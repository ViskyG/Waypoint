# Адресные правки скилов

Подготовлены изменения трёх глобальных скилов и двух проектных (EN/RU).
Они не переписывают пайплайн, не делают ChatGPT-капсулы обязательными и не создают
новых скилов/очередей. Содержание каждого добавления — в `sections/`, машинная
привязка к текущим исходникам — в `EDITS.json`.

`tools/stage_skill_edits.py` читает точные проверенные файлы из ваших checkout и
пишет **новые кандидаты и unified patches только в отдельный output-каталог**.
Исходные репозитории не изменяет, не коммитит и не устанавливает. Сначала проверяет
все SHA/якоря соответствующего набора; при изменённой базе останавливается, не
подставляя похожее место. Пример из корня архива:

```
python3 tools/stage_skill_edits.py --project-root /actual/Waypoint --skills-root /actual/agent-skills --out /new/staged-candidates
```

После проверки диффа N07 переносит разрешённые изменения в актуальную рабочую ветку
и выполняет `python3 tools/navigation_index.py --check` и `python3 tools/validate.py`
канонического репозитория. Назначение/имя/статус строк не меняются. При их изменении
обновить соответствующую строку каталога и регенерировать навигацию по существующим
правилам. Если в библиотеке нет полной русской версии старого глобального скила,
поставленный перевод ДОБАВЛЕНИЯ не выдаётся за полный перевод: каталог сохраняет
явное отсутствие до отдельно законченного перевода. У двух проектных скилов
существующие полные русские версии обновляются парно.

Новые версии остаются кандидатами до проверенного применения. Опубликовать исходник,
проверить структуру и установить на runtime — разные действия. Глобальная установка,
смена настроек Codex и расписаний этим архивом не выполняется. Новые контрактные
требования активируются только при соответствующей поддержке Waypoint; обычный
человеческий текст карты можно готовить раньше без обещания новой UI-возможности.

Тематические проверки поведения: самостоятельное чтение блока; совпадение Plan/Task;
настоящий результат предшественника вместо одного done; опциональная поставка чата;
устаревание алгоритмической проверки после изменения кода; отсутствие двойной
отчётности ради интерфейса. Это отдельная проверка поведения, не замена валидатором ссылок.
