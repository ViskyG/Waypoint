# Waypoint — дорожная карта следующего этапа

Производное представление `ROADMAP.plan.json`. Это план, не текущий журнал исполнения.

**MIXED.** 10 исполнимых пакетов, 1 контейнер и 1 внешний вход; 17 блокирующих связей с результатами/фазами. Не переисполнять C01–C07.

```text
N00 → N01 → N02 / N03 / N04 / N05 / N07 → N08
N00 → N06 → N08 (темы не ждут нового профиля)
N02 → завершение N03; N06 + референс третьей темы → N09.
N08 нужен для окончательной проверки N09, но N09 НЕ блокирует N08.
```

Общие файлы интегрируются одним владельцем. Предпочтительный последовательный порядок — не дополнительные логические рёбра.

## Что не делает эта карта
Она не запускает Codex/Runner/расписание, не задаёт реальные статусы и не содержит вымышленных агентов. Идентификаторы нового этапа добавляются к свежему экспорту через подготовленный guarded merge.

## Важные различия
Ввод референса — условие результата, не назначение платного исполнителя. Реализация пакета, прохождение приёмки, публикация скила и его установка — разные факты.

## Новый этап в работающем проекте
Не импортировать этот stage-only JSON как весь существующий проект. См. `../CODEX_START.md` и `../tools/prepare_stage_merge.py`.
