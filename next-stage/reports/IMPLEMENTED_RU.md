# Waypoint: результат следующей фазы, 17 октября 2026

> Последующее уточнение: [аудит соответствия 2026-10-17](../audit/CONFORMANCE_RU.md) выявил открытые расхождения. Этот отчёт сохраняет прежний объём проверки и не подтверждает полную текущую приёмку.

N00–N08 реализованы на существующем Waypoint в режиме MIXED. Локальная функциональная версия 0.2 работает с действующим Codex. N09 открыт: подтверждённого отдельного третьего графического референса нет. Все три темы и визуальная приёмка владельцем не объявляются завершёнными.

Сохранены существующая архитектура наблюдателя, идентификаторы C01–C07, старые задания и неизвестные расширения, исходный журнал, история версий и курсоры. Codex не перезапускался; его глобальные настройки, скилы и другие проекты не изменялись. Изменения общих файлов интегрировал один владелец; независимые контракты, интерфейс, алгоритмы и проверки делегировались с разделёнными областями записи.

Карта последовательно обновлялась в самом Waypoint: статусы и результаты записаны событиями; доступность выходов — отдельными matching receipts с отпечатком требования и явной рабочей копией. Новые версии импортировались от свежего head со стабильным request_id и проверкой идентичного повтора. История промежуточных исправлений сохранена.

## Выполненные проверки

- Первоначальный интегрированный pytest: **95 passed**. После дальнейших адресных изменений проверены затронутые наборы: **38 passed** для Store/API/профиля/зависимостей/алгоритмов; **21 passed** для чтения Codex и восстановления источника; **6 passed** для финального согласования авторского каталога. Эти наборы пересекаются, их количества не складываются. Полный набор не запускался после каждого файла.
- На backup настоящей базы проверены миграция, reopen, integrity_check и rebuild без чтения Codex: сначала **6262 события** схемы 2; затем **10295 событий** схемы 3, включая новые dependency/algorithm receipts. Тексты событий, хеши, ID, версии планов, request receipts, capture versions и source cursors совпали побайтно; производные таблицы восстановились идентично.
- При фактическом обновлении сервиса сохранены все **6937** ранее принятых событий; после возобновления наблюдателя журнал продолжил расти. База не заменялась архивной копией.
- После финального перезапуска сервиса сохранены head `v-bdcf9899dc6647c7`, все 10350 прежних событий, 17 dependency receipts и 6 algorithm receipts; поток продолжился (10360+). Все входы N08 и четыре текущих результата алгоритмов остались подтверждены. Доказательство: `N08-restart.json`.
- Реальная сессия Codex: **294** совпадения native ID/типа и **208** точных видимых текстов основного источника; **16** агентов семейства, **15** родственных связей. После догрузки: нет пропусков, дубликатов и расхождений проверенных данных/статусов; совпали 14 записей метаданных подагентов и 16 native identities курсоров. Контрольные RPC агентам не отправлялись.
- Настоящий Chromium с установленным Waypoint и реальными наблюдениями Codex: **16 проверок PASS**, включая три точных текста, вложенных агентов, фильтры, текущую карту, объяснение/assignment, четыре алгоритма, обе темы. Одно уникальное событие статуса обновило План и Карту без второго сообщения агента.
- Отдельный настоящий HTTP-сервис с явно синтетическими данными: **18 браузерных проверок PASS**, включая независимые окна, сохранение выделения и прокрутки, старые ошибки, безопасное отображение строк алгоритмов и одинаковые ID в разных проектах. Ещё 10 контролируемых UI-проверок покрывают запоздалые ответы; они не выдаются за подключение Codex.
- Оба автономных preview проверены в Chromium: встроены шесть модулей, нет внешних запросов и ошибок приложения. Дорожная карта не содержит вымышленных агентов и runtime-проверок; демонстрация интерфейса явно вымышленная.
- Генерация и валидация текущей карты: **279 ограниченных проверок**, JSON Schema, source references, disposable Store round-trip и совпадение производных представлений. Старые фронтиры завершённой фазы не использовались как текущие задания.

## Измерения

Это синтетические насыщенные истории через настоящий локальный HTTP и браузер на текущей машине. Для HTTP — три замера после одного прогрева; измерения не сравниваются с вымышленным baseline.

| Нагрузка | Первое чтение в браузере | Открытие Плана | Медиана HTTP state | Медиана фильтра старых ошибок |
|---|---:|---:|---:|---:|
| 100 блоков, 4043 сообщения | 277 мс | 54 мс | 46 мс | 1,32 мс |
| 300 блоков, 10243 сообщения | 383 мс | 80 мс | 139 мс | 1,85 мс |

Проверен отбор редких старых ошибок перед лимитом, несмотря на 500 более новых сообщений целевого блока. Среда, выборки, размеры ответов, RSS и отдельные значения сохранены в `../evidence/N08-performance.json`. Универсальная скорость, FPS и задержка передачи токенов не заявляются.

## Найденные и исправленные проблемы

1. При удалении read key из fragment терялся project deep link. Теперь удаляется только key, остальные параметры сохраняются; регрессия проверена в измерениях и реальном браузере.
2. Помощник авторского каталога добавлял четыре псевдонима поверх исходных ALG-ID. Реальный браузер выявил восемь записей вместо четырёх. Исправлено согласование по каноническим ID, сохранены неизвестные поля и история, ревизии повышены; удалены только распознанные псевдонимы помощника. Временное неподтверждение результата и последующее подтверждение сохранены в ledger.
3. Настоящая JSONL-запись вложенного агента размером **3 147 537 байт** превышала лимит 3 000 000. Введён ограниченный предел **16 МиБ**, сохранено атомарное отклонение слишком длинной записи без продвижения курсора. После успешного раунда чтения состояние источника восстанавливается отдельным событием без heartbeat-потока. После перезапуска только observer данные догрузились и сверка прошла.
4. Первый запуск сервиса при обновлении встретил ещё удерживаемую блокировку штатно завершающегося старого процесса. После подтверждённого выхода выполнен запуск без удаления lock-файла или базы.

Неудачные попытки браузерного harness из-за закрытого details и синтаксиса тестового селектора исправлены в тесте; они не выдаются за дефекты приложения. Автоматическая проверка разрешений одного составного импорта истекла по тайм-ауту; после разделения подготовки и короткого API-запроса импорт выполнен и проверен.

Из корня проекта доступны целевые команды:

```bash
waypoint/.venv/bin/python -m pytest -q waypoint/tests/test_stage2_store_api.py
waypoint/.venv/bin/python roadmap/tools/roadmap.py validate
waypoint/.venv/bin/python next-stage/tools/verify_stage2_live_browser.py .runtime/data /tmp/waypoint-browser-check.json
```

Последняя команда — явная целевая приёмка: она записывает один настоящий статус проверки в WPT-N08. Не запускайте повторно без причины. Для backup-проверки используйте `next-stage/tools/verify_stage2_migration.py` с новым приватным путём назначения, никогда не поверх рабочей базы.

## Оставшиеся ограничения

- **N09 awaiting reference:** третье вложение повторяет известный Obsidian, отдельного подтверждённого третьего референса нет. Нужен референс владельца, после него остаются только затронутые проверки темы. Полная визуальная приёмка трёх тем открыта.
- **INCIDENT_NOT_RECONSTRUCTED:** исходному историческому инциденту не сопоставлены подтверждённые ID/версия/хронология. Текущий независимо обнаруженный JSONL-gap не объявляется причиной того старого инцидента.
- Зашифрованные/не предоставленные источником скрытые рассуждения не восстанавливаются. Неизвестные сведения не синтезируются. Сквозная задержка токенов не измерялась.
- У проверок есть предупреждение сторонней Starlette/AnyIO о deprecated BlockingPortal alias; оно не приводило к ошибкам тестов.
- Кандидаты скилов: **PREPARED_NOT_PUBLISHED_NOT_INSTALLED**. Для execute-roadmap-efficiently поставленная база 2.0.1 отличалась от реально найденной 2.0.0; подготовлен ограниченный согласованный кандидат от фактического blob, а не заявлено применение отсутствующей версии. Глобальный `agent-skills` не изменён.
