# Исправление четырёх дефектов аудита

**Результат:** CONTRACT-F01–F04 исправлены поверх существующего Waypoint. Исправленная версия установлена на прежнем `http://127.0.0.1:8769`; принятая история, идентификаторы и ключи сохранены. Это адресная приёмка четырёх дефектов, а не закрытие всех находок аудита.

Запись, покинувшая фильтр/блок, удаляется из окна; отсутствие в ограниченной последней странице не считается удалением. | Chromium: видимый `msg-5` исчезает после смены типа; 39 остальных остаются даже после 140 новых сообщений; перенос `msg-6` за пределы блока тоже отражается. ## Фактически выполненные проверки

- [run1/RESULT.json](run1/RESULT.json): **15 успешных сценариев**, настоящий headless Chromium 143 → настоящий HTTP → временный Store, данные явно синтетические. Скриншоты — `run1/plan.png`, `run1/reader.png`. Это не доказательство подключения к Codex.
- [LIVE.json](LIVE.json): действующий локальный Waypoint после обновления, настоящий root IPC Codex и точное совпадение одного исходного сообщения через API и Chromium. RPC управления агентами не выполнялись, временная подписка снята, тексты и ключи не экспортированы. Это ограниченная живая проверка, а не повтор всей прежней сверки семейства.
- После перезапуска сохранены все **15 968** прежних событий: совпали ID и хеши всего префикса. Сохранены **1123** прежние пары agent/item и восемь версий карты; `integrity_check=ok`, очередь без ошибки. Observer продолжал работу. Приватный SQLite backup не входит в поставку.
- Один общий запуск [pytest.xml](pytest.xml): 131 passed, 1 failed. Найдена реальная побочная несовместимость нового health helper с явным demo. Исправлена; адресный повтор [pytest-health-followup.xml](pytest-health-followup.xml): 17 passed, включая добавленный demo regression. Остальные 131 успешных результата не объявлены повторным запуском на изменённом helper; изменение касается только ветки demo, затронутый набор повторён. Существующее предупреждение anyio о deprecated alias осталось.
- Дополнительные адресные запуски подагентов: зависимости/совместимость 20 passed (6 deselected), resolve API 1 passed, источник 14 isolated checks и API 1 passed. Эти пересекающиеся числа не складываются с общим suite. Первое сравнение health timestamp в новом тесте исправлено на сравнение одного момента времени после нормализации ISO; это была ошибка тестового ожидания. TestClient запускался вне ограниченного sandbox после зависания изолированного harness.
- Изменены точные ревизии ALG-DEPS, ALG-PAGE и ALG-READ, старые определения/наблюдения оставлены историческими. Новые correctness receipts привязаны к новым ревизиям; старые измерения не объявлены текущими.

## Что остаётся открытым

**F05–F07 не входили в эти четыре исправления:** item/pixel anchors и возврат окна фильтра, общий начальный фильтр, страницы истории алгоритмов. Поэтому N04-FIX остаётся частичным, N05-FIX открыт. N07-FIX сохраняет нерешённые вопросы доказательств и исторических привязок; N08-FIX не получает полной приёмки. N02-FIX и N03-FIX закрываются по собственным подтверждённым критериям. N09 по-прежнему требует третьего референса.

Прежние audit receipts и неудачные исходы не заменены. Настоящая привязка сообщений не реконструировалась по догадке. Проектные и общие кандидаты скилов уже содержат нужную дисциплину; новая глобальная установка/публикация или изменение других проектов не выполнялись.
