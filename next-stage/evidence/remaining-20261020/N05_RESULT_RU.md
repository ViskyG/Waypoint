# N05: ограниченная история алгоритмов завершена

Исправлен F07. Деталь показывает одну страницу до 100 свидетельств и переходы в обе стороны; проверены все 237 уникальных записей (100/100/37). Общие tested/measured/installed, конфликтующие проверки и количества рассчитываются по всей истории применимой ревизии. Старая неуспешная проверка за пределами хвоста не исчезает. Сравнения разрешают нужные ссылки вне страницы внутри того же алгоритма.

Реестр агрегирует компактные метаданные SQLite и не декодирует тела наблюдений. Деталь отбирает индексированные ID до чтения тел страницы; дополнительно читает только ссылки сравнений этой страницы. Это не обещание постоянной стоимости SQL-агрегации независимо от числа метаданных и не измерение универсальной скорости.

Новая производная проекция остаётся в schema 3, восстанавливается атомарно. Дополнительный review выявил пропуск после записи старой schema3-версией: при открытии теперь сверяются отсутствующие/лишние ID. Регрессия проверила missing+orphan с одинаковым числом строк, повторное открытие без чтения прежних тел, неизменность ledger/cursor/head и rebuild.
