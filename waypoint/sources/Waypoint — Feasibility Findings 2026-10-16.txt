IMPORTANT EXTERNAL CROSS-CHECK
Official Codex environment documentation https://learn.chatgpt.com/docs/config-file/environment-variables says CODEX_HOME controls state and should be writable, with CODEX_SQLITE_HOME for SQLite location. The Codex team clarified in https://github.com/openai/codex/issues/51293 that read-only CODEX_HOME can fail initialization even if sqlite/log paths are redirected; runtime writes including installation_id remain necessary. Thus P02's error is consistent with a known environmental prerequisite. App Server read APIs and cross-client live subscription remain unverified.
Documentation also confirms that Stop/SubagentStop hooks expect valid JSON on stdout when ending with exit code 0: https://developers.openai.com/de-DE/docs/hooks . The synthetic hook returning empty stdout must NOT be installed unchanged.
Official App Server documentation: https://learn.chatgpt.com/docs/app-server .
