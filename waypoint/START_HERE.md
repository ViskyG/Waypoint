# Waypoint delivery index

Verify the unmodified unpacked delivery: `python3 tools/verify_package.py`. This checks file integrity, not target behavior.

1. Owner summary: `README_RU.md`.
2. Whole-system design: `design/ARCHITECTURE.md`.
3. Exact data/API boundaries: `design/CONTRACTS.md`, `schemas/`.
4. Implementation state and selected hardening route: `design/IMPLEMENTATION_MAP.md`.
5. Local executor handoff: `CODEX_START.md`, `design/WORK_PACKETS.md`.
6. Verification: `design/ACCEPTANCE.md`, `evidence/RESULTS.md`.
7. Operations and privacy: `design/OPERATIONS.md`.
8. Run UI without service: `preview.html` (fictional data, same application assets).
9. Candidate skills: `skills/INTEGRATION.md`, then the selected EN/RU source only.
10. Session/publication state: `SESSION.json`, `handoff/PUBLICATION.md`.

Source authority: full owner Design Context and rev3 real-probe evidence under `sources/`.
New architecture choices are labelled as this design's choices, not attributed to the owner.
MIXED does not trigger Codex or an external action automatically. No public release license was chosen.
