# WPT-C06 — непрерывное чтение и измерения браузера

База: существующая реализация C01–C04 из архива, проверенная R00; новая система не создавалась. Работа выполнена в общей рабочей копии без Git, с отдельным владением web/browser файлами. Индекс C05.3 принят интегратором до насыщенного прогона. Контракт `/items?node/edge/agent&deep&before&limit&version` сохранён; `items`, `before`, `has_more` использованы настоящим браузером. Добавленный API `cursor` совместим с клиентом.

Ожидалось: поток карточек и открытого инспектора без потери места/выделения, рабочая вложенность, ограниченный DOM и измеренная большая карта. Получено: постоянные окна по карточке/инспектору; 24 сообщения на карточку, 100 в свежем инспекторе, до 200 при чтении предыдущих страниц. Внизу окно следует потоку; старое окно сохраняет место, показывает счётчик и кнопку «К последним». Индексированная дополнительная выборка обновляет revisions уже читаемых старых строк. Изменённый выделенный текст применяется после снятия выделения, чтобы его можно было скопировать. Ключ сообщения включает actor ID и item ID. Переключение direct/deep сохраняет отдельные окна, а исходные target IDs остаются видимыми.

Карточки, сообщения и actor cards обновляются по ключу. Pan/zoom сохраняет DOM видимых карточек, скрытые карточки снимаются; дальний масштаб сохраняет footprint. Учтены native события с пустым envelope: назначение берётся из текущей/предыдущей Store projection, неизвестный старый item инвалидирует чтение консервативно. Переполнение страницы уведомлений не оставляет открытые окна устаревшими. Исторические lifecycle-состояния агентов подписаны «История · event_msg.task_*» и не считаются доказательством живой активности. Inspector задания/приёмки/тестов/статуса обновляется только по изменённым данным; структурный diff не исчезает при постороннем событии.

Сохранены обе темы, 235 CSS px чата на масштабе чтения, ↑/предки/back и camera по scope, off-map drawer, ghost удалённой активной работы. Добавлены явные переходы через внешние связи, копирование block/native actor ID и клавиатурное перемещение/масштабирование canvas. Наблюдатель не отправляет команды агентам.

## Насыщенная карта: фактическая выборка

Linux 6.8.0-138-generic x86_64, glibc 2.39; AMD Ryzen 7 9800X3D, 8 доступных logical CPU, MemTotal 48,413,820 kB. Chromium 143.0.7499.4, headless, viewport 1660×1050, DPR=1. Каждый граф имеет три уровня, 24 вложенных actor, по шесть тестов/четыре критерия на узел, оригинальные чаты нескольких типов; два горячих узла по 500 сообщений, остальные по 30, отдельные сообщения на рёбрах.

Полная выборка HTTP timings, DOM counters, heap и токенов тем: `evidence/rich-browser-results.json`. Heap измерен CDP без принудительного GC, не является доказательством отсутствия утечек. API timings включают localhost HTTP и чтение ответа Python-клиентом; append latency включает commit/long-poll/state/DOM и ожидание Playwright. Первый render имеет только одну выборку. Overview 300-узловой карты ограничен viewport и минимальным zoom, поэтому одновременно смонтированы 160 корневых footprints, остальные доступны pan.

Измерения поддерживают текущие границы окна/viewport на этой машине: 300 узлов остаются доступны, а 500 сообщений каждого горячего узла не монтируются целиком. Большой `/state` всё ещё возвращается при уведомлениях: 1.48 MB и ~63 ms медианы для этого fixture; это явный предел текущей реализации, а не обещание FPS или SLA.

## Ограничения и границы доказательств

Живое подключение к действующему Codex, настоящие родственные threads и restart проверяет интегратор в C07; эти fixtures этого не подтверждают. Поток из 60 append на размер проверяет ограниченную непрерывную выборку, а не многочасовой soak. Реальные append/revision комбинированные сценарии проверены функциональным fixture; насыщенная выборка измеряет append. Нет человеческой оценки читаемости, полного accessibility audit, cross-browser/cross-machine гарантии, production SLA или гарантии отсутствия утечек. При actor highlighting намеренно приглушаются нерелевантные карточки; contrast-расчёт относится к обычному состоянию чтения. Финальный plan_version и применение статусов C06.1–C06.3 принадлежат интегратору; история и ID сохранены.

Изменённые исходники: `waypoint/web/app.js`, `waypoint/web/style.css`, `tests/browser_check.py`; новые fixtures/runners: `tests/run_browser_check.py`, `tests/rich_browser_check.py`, `tests/browser_details_check.py`. Производные артефакты: `preview.html`, synthetic screenshots/JSON в `evidence/`, этот отчёт. Store/API/collector/CLI этой веткой не изменялись. Глобальные настройки, скилы и другие проекты не изменялись.
