# Продолжение работы с Waypoint

Режим MIXED. C01–C07 — существующая реализованная база. Следующая фаза N00–N08 выполнена поверх неё; фактические доказательства и ограничения собраны в [IMPLEMENTED_RU.md](../next-stage/reports/IMPLEMENTED_RU.md). Не повторяйте завершённые пакеты по старому начальному frontier.

Источник структуры — `ROADMAP.plan.json`. Текущее состояние исполнения, история и подтверждения результатов — в действующем Waypoint. Перед новым изменением проверьте Git и текущий head, экспортируйте свежую карту и используйте её `base_version` со стабильным `request_id`. Не заменяйте рабочую БД архивной копией. Старые инструкции сохранены в `history/`.

Для задачи прочитайте её пакет и точный набор источников. В новых пакетах `reference_root: ../next-stage` разрешает пути исходного архива; для старых пакетов сохраняется прежняя база. Общие файлы меняет один интегратор; независимые области можно делегировать. Применяйте канонический `execute-roadmap-efficiently` через `skill-navigation`, не изменяя глобальные скилы без разрешения.

Waypoint — пассивный наблюдатель. Статус done не подтверждает наличие результата: typed requires проверяются общим resolver по неизменяемым свидетельствам, ревизии и рабочей копии. Не скрывайте unknown, conflict или позднее получение.

N09 доступен только после подтверждения отдельного третьего графического референса. Его отсутствие не отменяет функциональную приёмку N08. Предложенные изменения скилов подготовлены локально и не установлены глобально.
