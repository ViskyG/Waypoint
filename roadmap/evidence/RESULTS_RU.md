Проверяется новая структура работ и её непосредственная совместимость с предоставленным кодом Waypoint. Это не повторное проектирование и не приёмка всего продукта.

**Структура.** Native JSON Schema и `domain.validate_plan` приняли 20 узлов и 21 ребро. Parent/dependency связи согласованы; у всех блоков есть assignment/acceptance. Точные source_refs существуют. Сохранены C01–C07; готовые C01–C04 не стали повторными задачами. Проверена плановая независимость C05/C06 после R00 и внутренний стык C05.3→C06.3. Детали и среда в `VALIDATION.json`. Большая часть количества assertions — проверки отдельных refs/полей, не независимые продуктовые тесты.

**Native Store/API.** Настоящий код из исходной поставки импортировал план в одноразовую SQLite, прочитал/экспортировал его без потери `x_roadmap`, сохранил идемпотентность, объединил disjoint updates и отверг конфликт одного acceptance. **Настоящий локальный сервис и CLI.** Дополнительно выполнен `plan-import → packet → plan-export` через CLI, настоящий loopback HTTP и SQLite в отдельном временном каталоге. ## Воспроизведение

В окружении с тестовыми зависимостями поставленного Waypoint, из `roadmap/`:

```bash
python tools/roadmap.py render --check
python tools/roadmap.py validate
python tools/check_cli.py
```

Browser-проверка требует отдельно доступного Playwright и `/usr/bin/chromium`; устанавливать их глобально этот пакет не поручает. Автономный preview строится `python tools/build_preview.py`; поведение проверяется `python tools/check_preview.py`. После изменения authoring JSON сначала `render`, затем только относящиеся к изменению проверки. Не запускать полный кампейн P00–P11 ради документационной правки.
