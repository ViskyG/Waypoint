# Подготовка Waypoint к публикации

Репозиторий подготовлен для просмотра: корневой README объясняет назначение продукта, показывает предоставленный владельцем скриншот и содержит команды запуска, подключения и проверки. Публичная видимость и лицензия остаются отдельными решениями владельца.

## Что подготовлено

| Область | Результат |
|---|---|
| Главная страница | [README](../README.md): возможности, демо, подключение Codex, устройство, проверки и текущие ограничения |
| Демонстрация | [Оригинальный скриншот](images/waypoint-map.png), 1390 × 1251; скопирован без изменения изображения |
| Доступный запуск | Демо использует собственный каталог `.runtime/demo` и порт 8770; рабочая установка отделена от него |
| Границы продукта | Наблюдатель существующих сессий; внутренняя IPC-интеграция проверена на Linux, без обещания универсальной совместимости |
| Доказательства | README ведёт к актуальной приёмке и отдельно к настоящей проверке Codex; старые материалы сохранены как история |
| Приватное состояние | Рабочие базы, access/auth/binding и JSONL-журналы отсутствуют среди файлов Git; `.runtime/` исключён |
| Проверка секретов | История Git, подготовленные файлы и известные локальные capabilities проверены; машинная сводка — [PUBLICATION_AUDIT.json](PUBLICATION_AUDIT.json) |

Gitleaks сообщил два совпадения правила `generic-api-key` в исторических JSON-отчётах. Оба значения проверены: это SHA-256 файлов `waypoint/waypoint/client.py` и `waypoint/tests/test_authoring_next_stage.py`, совпадающие с их байтами. Они не скрыты allowlist и не удалены из истории. Точные места и классификация сохранены в машинной сводке. Приватные журналы сканирования и значения настоящих ключей в неё не включены.

Проверка шаблонов не гарантирует отсутствие любых чувствительных сведений. В репозитории сохраняются история разработки, локальные пути, технические ID, отчёты и снимки интерфейса. Предоставленный владельцем новый скриншот намеренно показывает настоящую работу над проектом. Git-история и существующие доказательства при подготовке не переписывались.

## Что остаётся решением владельца

**Лицензия не назначена.** Файл `LICENSE` не создан без выбора владельца; README отражает это состояние. Подготовка к публикации не объявляется выпуском под открытой лицензией.

**Репозиторий остаётся приватным.** Переход в public, создание публичного релиза и загрузка артефактов в него не выполнялись. Подготовленный README и изображение можно просмотреть в текущем GitHub-репозитории перед этим шагом.

Открытый N09 относится к третьему графическому референсу и указан в README. Он не скрыт формулировкой о готовности доступного функционального объёма.

## Что не изменялось

Код приложения, структура дорожной карты и исторические результаты тестов не менялись. Рабочая база не заменялась и вручную не редактировалась. Полный suite и живое подключение ради документации повторно не запускались; используются уже сохранённые доказательства. Глобальные скилы, настройки Codex и другие проекты не затронуты.
