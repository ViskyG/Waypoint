# Waypoint 0.2 — локальный наблюдатель

**Последнее обновление, 2026-10-20:** доступный функциональный объём N00–N08 и шесть пакетов ремонта завершены. F01–F07 исправлены; новая приёмка подтверждает текущие окна чтения, default фильтра, страницы алгоритмов, происхождение проверок, сохранность истории и настоящего Codex после перезапуска. [Итог и ограничения](next-stage/evidence/remaining-20261020/FINAL_RU.md). Открыт N09: нужен подтверждённый третий графический референс.

Исторический [аудит 17 октября](next-stage/audit/CONFORMANCE_RU.md) и [ремонт первых четырёх дефектов](next-stage/evidence/four-defects-20261017/FINAL_RU.md) сохранены. Их тогдашние открытые состояния не являются текущим списком работ. Старые неизвестные старты/привязки не восстановлены по догадке; пропавший старый N07 pin честно заменён новым текущим доказательством.

Для проектировщика, исполнителя и аудитора действует общий [порядок работы с картой](next-stage/skills/conformance/WAYPOINT_WORKFLOW.md). Проектные скилы уточнены; кандидаты общих скилов подготовлены в [skills/conformance](next-stage/skills/conformance/README_RU.md), без глобальной публикации или установки.

Существующий Waypoint дополнен по следующей фазе N00–N08. Исходники C01–C07, идентификаторы, принятые события и версии карты сохранены. Подробный результат: [отчёт следующей фазы](next-stage/reports/IMPLEMENTED_RU.md). Проверки реального Codex и синтетических данных описаны отдельно.

Отображение готовности и регистрация проверок уточнены после осмотра владельцем: [цвета статусов и основания завершения](next-stage/reports/COMPLETION_UI_RU.md).

Рабочий сервис доступен на `http://127.0.0.1:8769`. Приватную ссылку чтения получите локально:

```bash
cd waypoint
.venv/bin/python -m waypoint --data ../.runtime/data url
```

Каталог проектов открывается первым. В проекте доступны Карта, План и Алгоритмы; в задании отдельно показаны объяснение для владельца и инструкции исполнителю. Фильтр действует на конкретное окно; кнопка «По умолчанию для новых окон» задаёт общую начальную настройку. История алгоритма открывается страницами. Waypoint наблюдает события и не управляет агентами.

Основная карта — [roadmap/ROADMAP.plan.json](roadmap/ROADMAP.plan.json), контрольный снимок действующей структуры. Статусы, доказательства и сообщения хранятся в приватной SQLite-базе. Для изменения работающей карты сначала экспортируйте свежую версию; не импортируйте начальный снимок поверх существующей установки. Подробности запуска и восстановления: [LOCAL_RUN_RU.md](waypoint/LOCAL_RUN_RU.md).

[Автономная карта](roadmap/PREVIEW.html) показывает структуру без живого исполнения. [Демонстрация интерфейса](waypoint/preview.html) содержит явно вымышленные данные. Исходный архив следующей фазы сохранён отдельно; его материалы находятся в `next-stage/`.

N09 остаётся открытым: нужен подтверждённый третий графический референс. Две известные темы реализованы; приёмка всех трёх не заявлена. Предыдущие предложения скилов сохранены в `next-stage/skills/candidates/`, актуальные дополнения аудита — в `next-stage/skills/conformance/`; глобальный `agent-skills` не изменён.
